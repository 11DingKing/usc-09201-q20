# 森林游客承载预警

面向高山森林康养景区的承载力预警系统：汇集**住宿在店、入口计数、步道/水源点状态与生态阈值**，向景区管理方与多家住宿经营者发布**分区等级**（正常/关注/预警/限流）与**分流替代建议**，解决周末步道与水源点逼近生态上限、经营者各自按单店房量接客、静态限额无法协同的问题。

## 快速开始

- `npm start` 启动 HTTP 服务（默认 `:3000`），`GET /health` 健康检查
- `npm test` 运行单元与接口测试
- `npm run drill` 运行**国庆前联合演练**：关闭热门步道并注入两批晚到客流，输出分区压力、经营提示与隐私边界的检查报告

## 设计要点

- **迟到数据**：匿名计数按发生窗口入库，事件级幂等去重，设备离线恢复后的补报、网络重发都不会重复计数
- **团体拆分**：整团与分批上报自动对账（取两者较大值），分批按批号判重，超预约规模记异常但不丢数据
- **防跳变**：分区等级采用进入/退出双阈值 + 连续确认的迟滞机制；限流等级一次评估即升级（安全优先），告警解除需连续回落
- **阈值临时下调**：降雨等场景按生效窗口临时下调生态阈值，多调整取最严格值，到期自动恢复
- **预测预警**：在店人数折算为预计入园量，最多把等级推至「预警」；「限流」必须由实测触发
- **隐私边界**：只接收聚合计数，携带个人字段的负载整体拒绝（422）；团体标识按日散列入库、日切弃盐；对外小计数（<5）抑制；不保存任何可还原个人轨迹的数据
