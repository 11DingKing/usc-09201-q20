# 森林游客承载预警

面向高山森林康养景区的游客承载预警服务。系统汇集**住宿在店、入口匿名计数、步道状态、生态阈值**四类数据，计算分区实时压力，向多家经营者统一发布**分区等级与替代建议**，解决降雨、临时封闭、散客涌入等情形下"各家按单店房量接客、无法协同"的问题。

## 快速开始

```bash
npm start          # 启动服务，默认 http://localhost:3000（PORT 环境变量可改）
npm test           # 运行全部单元、HTTP 与联合演练测试
curl http://localhost:3000/health
```

接口通过 `x-role` 请求头区分角色：`device`（计数设备）、`hotel`（住宿经营者）、`operator`（经营者）、`manager`（景区管理方）。详见 [docs/api.md](docs/api.md)。

## 核心能力

- **分区压力**：分区负荷 = 在店住宿（团体拆分去重后）+ 当日净入园，比上有效生态阈值；营业日按 UTC+8 划分。
- **四级预警**：正常 / 关注（0.75) / 预警（0.90) / 管制（1.00)。升级立即生效；降级需跌破退出线（0.70/0.85/0.95）并满足最短驻留（默认 10 分钟），比率在阈值附近波动不会反复跳变。
- **经营协同**：按等级给出行动清单；预警及以上自动推荐仍有富余的替代分区；封闭步道与数据质量（设备离线、迟到批次、团体超申报）随建议一并下发。
- **幂等与迟到数据**：`report_id` / `batch_id` / `override_id` 均为幂等键，设备重试不产生重复计数；迟到批次按发生时间补入对应营业日并触发重估。
- **阈值临时下调**：带生效窗口的临时阈值，窗口内取最小值，到期自动恢复。
- **隐私边界**：只保存聚合计数；团体凭证以"盐 + 住宿日"哈希落库，当日可去重、跨日不可关联；个人轨迹不可还原；`GET /privacy/audit` 可随时审计存储内容。
- **联合演练**：`POST /drill/run` 在隔离状态上重演"关闭热门步道 + 阈值下调 + 两批晚到客流 + 设备重试 + 出园回落"，输出压力时间线、通知序列、经营提示与隐私检查报告。

## 目录结构

```
src/
  server.mjs      HTTP 启动入口
  app.mjs         路由、角色鉴权、JSON 解析
  engine.mjs      数据接入与评估编排（幂等、重估触发）
  pressure.mjs    分区压力与有效阈值计算
  levels.mjs      等级状态机（滞回 + 最短驻留）
  alerts.mjs      告警生命周期（发布/升级/降级/解除，仅迁移时通知）
  advisories.mjs  经营者行动建议与替代分区推荐
  privacy.mjs     团体凭证哈希与隐私审计
  drill.mjs       国庆前联合演练场景
  seed.mjs        分区/步道/计数设备基础数据
  store.mjs       内存存储与数据版本
  config.mjs      阈值、滞回、驻留等配置
docs/
  domain.md       领域约定
  api.md          接口说明
test/             node:test 测试（单元 + HTTP + 演练）
```

## 环境变量

- `PORT`：服务端口，默认 3000
- `TOKEN_SALT`：团体凭证哈希盐，生产环境必须设置为受控随机值
