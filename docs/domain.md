# 森林游客承载预警领域约定

项目面向集体林权改革与林下产业协作场景，业务记录需要区分来源、发生时间与当前有效版本。涉及个人、机构或敏感地点的信息只应向职责范围内的角色开放，所有对外结果都应能够追溯到采用的数据版本。

## 概念模型

- **分区（zone）**：承载评估与等级发布的最小区域，具有基础生态容量与特色标签（tags）。
- **点位（site）**：分区内的步道（trail）或水源点（water），各自有容量与开放状态；点位局部过载同样抬升分区等级。
- **经营者（operator）**：住宿经营者，归属分区，上报在店人数（仅聚合计数）。
- **设备（device）**：入口（entrance）或点位（site）计数设备，按固定间隔上报流量；离线时其分区标记为 degraded。

## 事件（全部按 eventId 幂等）

| 事件 | 内容 | 关键语义 |
| --- | --- | --- |
| 流量窗口 | 设备、窗口起止、进/出人数 | 迟到数据按发生窗口归入；重发判重 |
| 在店上报 | 经营者、在店人数、发生时间 | 同一经营者按发生时间最新者为准 |
| 点位状态 | 点位、open/closed、生效时间 | 按生效时间最新者为准 |
| 阈值调整 | 目标、系数、生效窗口、原因 | 窗口内多调整取最严格值，到期自动恢复 |
| 团体预约/到园 | 整团（whole）或分批（part） | 对账取整团与分批合计的较大者；分批按 partId 判重 |

## 等级与告警

- 等级：0 正常、1 关注、2 预警、3 限流。
- 进入/退出双阈值 + 连续确认：升级需连续确认（限流一次即升），降级需连续回落，避免边界附近反复跳变。
- 预测分量（在店折算）最多把等级推至「预警」；「限流」必须由实测触发。
- 告警：等级 ≥2 开启，回落至 ≤1 解除；同一分区同一时间最多一条未解除告警，等级在 2/3 间变化只在告警内留痕。
- 建议：等级变化时发布，内容键（分区+等级+替代集合）相同且在冷却期内不重复发布；等级归零时全部解除。

## 追溯

每次评估都基于显式时间参数重算，发布视图（分区状态、建议、提示）可带 `?at=` 回溯任意时刻所采用的数据版本。
