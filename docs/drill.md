# 国庆前联合演练

`npm run drill` 在独立引擎实例上回放 2026-09-26（国庆前最后一个周末）的联合演练，全程确定性、可重复。退出码非零表示存在未通过项。

## 场景

- **分区**：A 云顶核心区（容量 800，含热门步道 T1 与水源点 W1）、B 溪谷缓冲区（600）、C 观景台区（400）
- **经营者**：H1/H2 位于 A 区，H3 位于 B 区；入口设备 D_A、D_B 每 15 分钟上报

## 时间线（UTC+8）

| 时刻 | 事件 | 期望表现 |
| --- | --- | --- |
| 08:05 | 在店上报（A 区 250 人） | 预测基线建立，等级正常 |
| 10:30 | 降雨，A 区阈值临时下调 25%（800→600） | 容量收紧，预测挂起「预警」 |
| 10:50 | 连续确认 | A 升「预警」，告警开启，建议发布（分流 B、C） |
| 11:00 | 热门步道 T1 临时封闭 | 状态可见，建议含绕行提示 |
| 11:00–12:00 | D_A 离线，窗口数据迟到 | 分区标记 degraded，等级维持不跳变 |
| 12:10 | **第一批晚到客流**：补报离线窗口（重发一次） | 重发判重，实测超载 → 快速升「限流」 |
| 12:15–12:22 | **第二批晚到客流**：60 人团体先整团上报、后拆分三批（一批重发） | 对账后只计 60 人，分批重发判重 |
| 15:00–16:00 | 客流离场，阈值调整 16:00 到期 | 连续回落确认 |
| 16:20 | 回落确认完成 | 等级归零，告警解除一次，提示清空 |

## 检查项（13 项）

迟到补报判重 · 团体拆分对账 · 设备离线标记与恢复 · 分级升级且无反复跳变 · 告警生命周期 · 经营建议分级发布与冷却 · 经营者提示（限流指令 + 分流准备） · 阈值临时下调生效与恢复 · 步道封闭可见 · 预测预警 · 隐私边界（无个人字段、团体标识不落盘） · k-匿名小计数抑制 · 终态计数闭合

演练脚本位于 `src/drill.mjs`（场景与检查）与 `scripts/drill.mjs`（报告输出），`test/drill.test.mjs` 将其纳入回归。
